# Final manuscript + rebuttal cross-check protocol

## Required source inventory

For a comprehensive audit, request/use the latest provided manuscript, point-by-point reply, main figures, supplementary figures/tables, and decision letter (if available). Do not claim complete figure/source alignment when only the manuscript and rebuttal are present.

## Audit pass 1: reviewer obligations

Build a private matrix of:

`Reviewer/Editor point → exact requirement → rebuttal claim → manuscript evidence (page/section/figure) → status: supported/partial/missing/unknown → recommended fix`.

Special checks:
- Reviewer requests direct COL6A5–ANTXR1 binding proof: did authors do Co-IP/GST/fragment binding? If not, is that explicit, limits acknowledged, full manuscript and graphical abstract cautious?
- Small in-house n = 3: is discussion limited to internal samples, not mistaken for TCGA?
- Second CArG site: does Results compare both single mutants and double mutants and avoid absolute nonfunction claims?
- Office siRNA minimum two: did two independent siRNA sequences actually produce functional validation, not merely screening?
- Office full Methods: every output panel has corresponding sufficient steps.

## Audit pass 2: internal evidence

- Verify abstract↔Results↔Discussion mechanistic strength and animal model type.
- Each figure panel ↔ text citation ↔ legend ↔ assay in Methods; identify missing or stale labels.
- Inspect the user-supplied final actual graphs/images for mismatch if available; do not assure no duplication from prose.
- Antibodies, cell lines, species, mice, sample sizes, actual assays and time points in Methods are consistent with figures.
- Human vs mouse qPCR primer sequences and nomenclature are correct for assay tissue source.
- Different models, HUVEC treatment paths, and partial rescue magnitude must not be conflated.

## Audit pass 3: references and stats

- All in-text numeric citations map to bibliography entries, and vice versa; check reference metadata and topical support.
- New references inserted in rebuttal may have independent numbering, but author/title/DOI content should match the main article counterpart.
- Clarify matched clinical samples (paired analysis); independent biological repeats vs technical replicates; multiple comparisons; repeated-measures growth data; survivor analysis and matching figure legend claims.
- Validate causal claims separately from statistical significance.

## Audit pass 4: language, layout, delivery

- Read final render for stranded headings, page numbering, broken labels in graphical abstracts, line wrap and space errors, section heading cases, species and gene italic formatting.
- Highlighted changes in `grey` if this is stated in rebuttal; compare against previous submitted version if available.
- Avoid duplicated paragraphs after cover-letter signature and duplicative explanations of technical difficulty.
- Page numbers are **final-render dependent**; confirm every location stated in rebuttal after re-pagination.

## Report format

Present a prioritized numbered issue list, each as:

`[严重程度] 位置（文件、章节、最终页码/图号） → 原文片段/具体证据 → 为什么有问题 → 可操作的英文修改或核实步骤`.

Use clear distinction:
- **Confirmed defect:** directly verified.
- **Probable scientific/method concern:** check experimental records or external primary source.
- **Unverifiable from available files:** state missing files/data and limit of conclusion.

When user only requests assessment, **do not create or modify an artifact**. State that a perfect submission certification is not possible without original experimental records, figures, journal criteria, and references where applicable.
